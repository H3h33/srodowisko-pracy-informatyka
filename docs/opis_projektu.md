# Opis projektu

Projekt dotyczy aplikacji wspierającej firmy w monitorowaniu zużycia zasobów IT.  
Rozwiązuje problem braku przejrzystości i nadmiernych kosztów operacyjnych.

## Grupa docelowa

Małe i średnie przedsiębiorstwa, które chcą optymalizować swoją infrastrukturę IT  
oraz lepiej kontrolować koszty zasobów (serwery, usługi chmurowe, licencje).

## Kluczowe funkcjonalności

- Dashboard kosztów zasobów IT
- Alerty przekroczeń ustalonych progów kosztowych
- Proste raporty miesięczne (podsumowanie kosztów, trend w czasie)
